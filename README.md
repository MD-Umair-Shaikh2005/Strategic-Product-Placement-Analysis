# Strategic-Product-Placement-Analysis

## Project Overview

This project analyzes how product positioning affects sales performance and consumer behavior. Using data visualization techniques in Tableau, the project identifies the most effective placement strategies such as endcap, aisle, and shelf positioning to improve product visibility and increase sales.

## Dataset

The dataset used in this project was obtained from Kaggle.

Dataset Link:
https://www.kaggle.com/datasets/amitvkulkarni/impact-of-product-positioning-on-sales

The dataset contains information about product placement, pricing, promotions, consumer demographics, and sales volume.

## Data Preparation

The dataset was cleaned and prepared using Python in Google Colab. The following preprocessing steps were performed:

* Removed duplicate records
* Checked for missing values
* Verified data types
* Exported cleaned dataset as CSV

The cleaned dataset is stored in the **data** folder.

## Dataset Features

The dataset contains the following fields:

* Product ID – Unique identifier for each product
* Product Position – Placement location (Endcap, Aisle, Shelf)
* Price – Selling price of the product
* Competitor Price – Price of competitor products
* Promotion – Indicates promotional offers
* Foot Traffic – Number of customers passing the product location
* Consumer Demographics – Target consumer group
* Product Category – Category of the product
* Seasonal – Seasonal or non-seasonal product
* Sales Volume – Number of units sold
